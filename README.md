# ML Fundamentals

Working through core Python, NumPy, and pandas exercises — the groundwork before moving into real machine learning projects.

## What's in this repo

- `grades.py` — Python fundamentals refresher: functions, conditionals, and return values.
- `stats.py` — Intro to NumPy: computing and displaying stats on a small dataset.
- `transform.py` — Linear algebra basics translated into code (vectors, matrix transformations).
- `pandas_intro.py` — Intro to pandas: loading, cleaning, and exploring a real dataset.
- `titanic.csv` — The dataset `pandas_intro.py` works with (Titanic passenger data).

## Why this exists

This is the start of a self-directed AI/ML learning track running alongside my CS degree, building the foundations — math, classical ML, deep learning, and AI engineering — toward real, original projects.

## Tools

Python, NumPy, pandas, git/GitHub.
